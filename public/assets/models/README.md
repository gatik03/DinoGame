# Neon Runner model assets

The optional player model is loaded from `player.glb`. Expected animation clip
names are `idle`, `run`, `jump`, `fall`, `duck`, `roll`, and `death`.

Obstacle visuals currently use procedural neon meshes. Future GLB files can be
added here without changing gameplay or collision code. Keep models licensed
for redistribution and aligned to the 2D gameplay bounding boxes.
